# Junwoo Park — GitHub Pages Portfolio

This folder is ready to publish as a static GitHub Pages site.

## Files

- `index.html` — deployable portfolio home page
- `assets/profile.jpg` — browser-compatible profile image converted from the original HEIC
- `assets/IMG_2942.heic` — original profile image preserved
- `assets/kimst-2025-paper.pdf` — local conference paper PDF
- `source/notion-export-original.html` — untouched original Notion HTML export
- `.nojekyll` — tells GitHub Pages to serve the site as plain static files

## Publish

1. Put the contents of this folder at the root of your GitHub Pages repository.
2. Commit and push.
3. In GitHub: **Settings → Pages → Build and deployment → Deploy from a branch**.
4. Select your Pages branch (commonly `main`) and `/ (root)`.

All original visible Notion text is retained in `index.html`; the layout, navigation, browser compatibility, and links were enhanced for GitHub Pages.
